LinRaskrLP Local
================

Запуск:
1. Распакуйте архив в отдельную папку.
2. Откройте файл index.html двойным щелчком.
3. Интернет, Excel и установка программ не требуются.

Запуск через Docker:
1. Откройте PowerShell в папке проекта.
2. Выполните: docker compose up --build -d
3. Откройте в браузере: http://localhost:8081
4. Остановить контейнер: docker compose down

База данных:
- Docker запускает отдельный контейнер MariaDB: linraskrlp_db.
- Данные хранятся в volume: linraskrlp_db_data.
- В БД сохраняются проекты, расчёты и действия пользователя.
- Кнопка «Сохранить в БД» сохраняет текущий ввод и последний результат.
- Кнопка «История БД» показывает последние сохранения и действия.
- Кнопка «Загрузить из БД» показывает список проектов; нажмите «Загрузить» у нужной записи.

Использование:
- В блоке «Есть» укажите длину и количество заготовок.
- Пустое количество означает неограниченный запас.
- В блоке «Нужно» укажите размеры и количество деталей.
- «Расчёт DP» выполняет быстрый последовательный раскрой.
- «Расчёт LP» подбирает комбинации с меньшим остатком.
- «Проверить» проверяет ввод перед расчётом.
- «Сравнить DP/LP» показывает, какой расчёт лучше.
- «Лучший расчёт» сразу выбирает лучший вариант.
- «Отобразить» возвращает скрытую схему/решение.
- «День/Ночь» переключает светлую и тёмную тему.
- «Загрузить из БД» восстанавливает старый ввод и результат расчёта.
- Проект можно сохранить в JSON и затем открыть кнопкой «Открыть».
- PDF сохраняется через окно печати: выберите «Сохранить как PDF».

Важно: файлы index.html, style.css и app.js должны находиться в одной папке.
